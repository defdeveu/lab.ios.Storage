# Storage lab

An iOS teaching application for exploring how several local persistence APIs
store the same piece of data.

## Requirements

- Xcode 27 or newer on Apple silicon;
- iOS 17 or newer.

Open `lab.ios.Storage.xcodeproj` and run the `lab.ios.Storage` scheme. The
XCTest target covers deterministic storage behavior and the configuration of
the platform storage APIs.

The repository uses `master.challenge` for the hands-on starting point and
`master.solution` for the post-exercise reference implementation. Detailed
challenge and solution design is intentionally kept out of this client README.
